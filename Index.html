TAG 1 : TABLE TAG

Definition : The table tag creates a table to organize data in rows and columns.

Function : Holds all the rows and columns, organizing data in a grid

TAG 2 : THEAD TAG

Definition: Defines the header section of a table.
Function: Groups rows and column ,is product , prices.

TAG 3 : TR TAG

Definition: Defines a table row
Function: Create one horizontal line of cells inside a table.

TAG 4 : TD TAG

Definition: Define a table data cell.
Function: Holds the actual content in rows, one per column.
